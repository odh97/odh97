# 캐릭터 파일을 넣는 자리

실제 캐릭터 파일은 포함하지 않았습니다. 이 파일은 이미지가 아닌 안내 문서입니다.

1. 본인이 별도 Work에서 제작한 캐릭터를 PNG로 저장합니다.
2. 이 폴더에 정확히 **avatar.png**라는 이름으로 넣습니다(대소문자 구분).
3. 루트 README.md에서 avatar.png 이미지 태그만 주석 밖으로 꺼냅니다.

권장: 투명 배경, 정사각형 PNG, 표시 너비 144px. 원본의 픽셀 선명도를 확인해 주세요.
빈 PNG나 다른 캐릭터를 대신 넣지 않았으므로, 추가 전에는 README에 깨진 이미지가 나타나지 않습니다.
